# Archived Planning Documents

These documents are retained for historical context and decision rationale. They are not the current product or implementation authority.

For current scope, MVP status, architecture, Google/OAuth considerations, and sequencing, use [Creator Workspace Current Product Plan](../../creator-workspace-current-product-plan-2026-08-11.md).

For accepted technical and product decisions, use the [decision log](../../decision-log.md) and [ADRs](../adr/README.md).

Archived documents include earlier roadmaps, backlogs, workflow diagrams, detailed feature specifications, stack recommendations, and user-story plans. If an archived document conflicts with the current plan or an accepted ADR, the current plan and ADR win.
